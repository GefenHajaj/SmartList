# Smart List App Code Base
This is the code for an app called Smart List.

## What is Smart List?
Smart list is an app that lets you create and share lists, edit those lists with friends and family,
and see the changes made to the list in real time.

For example, you can create a list for house shopping, for an event or a party or even to know
what everybody in the office needs.

## Technical Info
The server is written entirely using django.
It uses a MySQL server to store the data.

The app is written using Flutter - which allows us to write the app both for android and iOS
with on code base.
